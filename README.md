# Pulse — SaaS Landing Page Concept

A responsive, front-end landing page for a fictional ecommerce analytics product called Pulse.

## Portfolio disclosure
This is a self-initiated concept created for portfolio demonstration. Pulse is fictional, and all dashboard values are illustrative. No client commissioned this work.

## Features
- Responsive desktop and mobile layouts
- Semantic HTML and accessible navigation labels
- Responsive dashboard preview with illustrative chart
- Mobile navigation toggle
- Reduced-motion preference support
- No framework or build step required

## Run locally
Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html` — page content and structure
- `styles.css` — visual design and responsive styles
- `script.js` — mobile navigation interaction

## Before commercial delivery
Replace the fictional brand, copy, metrics and email CTA with client-approved content. Test links and forms, confirm browser support, and agree scope and deployment responsibilities with the client.
